### 1) 네이티브 앱 개발(Native App Development)이란?
- 네이티브 앱은 특정 운영체제(OS), 즉 `iOS` 또는 `Android`만을 위해 전용으로 만들어진 앱
- `iOS` 앱
  - 주로 Apple에서 만든 `Swift`나 `Objective-C`라는 프로그래밍 언어 사용
  - 개발자의 관점 = 마치 Safari 전용 웹사이트를 만드는 것
- `Android` 앱
  - Google에서 만든 `Kotlin`이나 `Java`라는 언어 사용
  - Android 개발 = 마치 Chrome 전용 웹사이트를 만드는 것
- 하지만 웹과 달리, 모바일 앱은 각 플랫폼마다 `완전히 다른 언어`와 도구를 사용해야함

### 1-1) 네이티브 앱 개발의 장점
1. `최고의 성능` : 해당 OS에 최적화된 언어와 도구를 사용 → 속도가 매우 빠르고 부드러움
- 예&#41; 복잡한 3D 게임이나 실시간 영상 처리 앱에서 네이티브 개발이 필수적임
2. `모든 기능 접근` : 스마트폰의 카메라, GPS, 센서 등 기기 고유의 모든 하드웨어 및 소프트웨어 기능에 제약 없이 접근가능
- 예&#41; 생체 인식(지문, Face ID), NFC 결제, AR(증강현실) 등 최신 기능을 가장 빠르게 활용가능
3. `최신 기능 지원` : 새로운 OS 버전이 출시될 때마다 제공되는 최신 기능을 가장 빠르게 적용가능
- 예&#41; iOS 17의 새로운 기능을 Swift로 바로 사용할 수 있지만, 크로스 플랫폼 도구는 업데이트를 기다려야 할 수도 있음

### 1-2) 네이티브 앱 개발의 단점
1. `두 번의 개발` : iOS와 Android, 두 개의 플랫폼을 모두 지원하려면 두 가지 언어로 두 번 앱을 만들어야 함 → 개발 시간과 비용을 두 배로 증가
- 실무 예시 : "로그인 기능 추가"라는 요구사항이 있으면, Swift로 iOS 버전을 만들고, Kotlin으로 Android 버전을 따로 만들어야 하고, 버그 수정도 두 번 해야 함
2. `별도의 전문가 필요` : iOS 개발자와 Android 개발자가 각각 필요할 수 있음
- 팀 구성 예시 : 스타트업이나 소규모 팀에서는 한 명의 개발자가 두 언어를 모두 마스터하기 어려움
3. `학습 곡선이 가파름` : 웹 개발자라면 JavaScript를 버리고 Swift나 Kotlin을 처음부터 배워야함
- 비유 : JavaScript로 웹을 만들다가, 갑자기 Python으로 웹을 만들라고 하는 것과 같음
