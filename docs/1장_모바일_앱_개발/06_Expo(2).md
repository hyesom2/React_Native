### 6-1&#41; Expo Go와 Development Build 소개
| 구분 | Expo Go | Development Build (개발용 앱) |
| :--: | :--: | :--: |
| 용도 | 가장 빠른 테스트 및 개발 |	Expo Go로 지원 안 되는 기능 테스트 |
| 설치 방법 |	App Store 또는 Google Play에서 Expo Go 앱 설치 | EAS Build로 프로젝트 전용 앱을 빌드 후 설치 |
| 특징 |개발 중인 앱을 Expo Go 앱 내부에서 실행 | 프로젝트 전용의 독립된 개발 앱 실행 |
| 제약 사항 |	Expo Go에 포함되지 않은 네이티브 모듈 (예: 아주 특수한 결제 모듈)은 테스트 불가 | Expo Go보다 빌드 시간이 더 필요함 |
| 추천 대상	| 초심자, 대부분의 앱 개발 | 특수한 네이티브 모듈이 필요한 경우 |

### ※ Expo Go
- 초심자가 가장 많이 사용하게 될 방법
- 개발 중인 코드가 서버에서 로드되어, 이미 설치된 범용 컨테이너 앱인 Expo Go 내부에서 실행됨
- 대부분의 Expo SDK 기능을 테스트할 수 있음
- 비유 : 마치 브라우저에서 여러 웹사이트를 열 수 있는 것처럼, Expo Go 앱 하나로 여러 프로젝트를 테스트할 수 있음
- 실제 사용 시나리오
1. 여러 프로젝트를 동시에 개발 중
2. 각 프로젝트마다 별도 앱 설치 불필요
3. QR 코드만 스캔하면 즉시 전환 가능
- 지원 기능 : Expo SDK의 대부분 기능 (카메라, GPS, 알림, 파일 시스템 등)

### ※ Development Build
- Expo Go로 테스트할 수 없는 기능(예: 커스텀 네이티브 모듈을 추가한 경우)이 필요할 때 사용
- 개발 중인 프로젝트의 네이티브 모듈까지 포함하여 `프로젝트 전용의 테스트 앱`을 따로 만들어 실행
- 사용시기
  - Expo SDK에 없는 특수한 네이티브 라이브러리를 사용해야 할 때
  - 앱의 네이티브 설정을 커스터마이징해야 할 때
  - 프로덕션 빌드와 유사한 환경에서 테스트하고 싶을 때
- 실제 사용 시나리오
1. Development Build 생성
```bash
# 2.
$ eas build --profile development --platform ios
```
3. 생성된 앱을 기기에 설치
4. 이후 Expo Go처럼 Fast Refresh 지원
- 장점 : Expo Go의 편의성 + 커스텀 네이티브 모듈 지원

### 6-2&#41; Expo 사용 시 고려 사항(Trade-offs)

### ※ 실무 관점에서의 고려사항
1. 네이티브 모듈 추가의 제약 (Legacy) : 과거에는 Expo가 지원하지 않는 아주 특수한 네이티브 모듈(예: 특정 하드웨어 전용 라이브러리)을 사용할 때 어려움이 있었음
- 현재 상황 : Expo SDK가 매우 풍부 → 대부분의 기능을 지원
- 예외 케이스
  - 특정 하드웨어 제조사의 전용 SDK
  - 아주 최신 OS 기능 (Expo SDK 업데이트 전)
  - 기업용 특수 보안 라이브러리
- 해결책 : Development Build를 사용하면 커스텀 네이티브 모듈을 추가할 수 있음

2. `eject` 또는 `prebuild` : 현재는 Expo에서도 `EAS Build`와 `expo prebuild`명령을 통해 언제든지 네이티브 폴더(iOS/Android)를 노출시켜 순수 React Native 프로젝트로 전환하거나 커스텀 모듈을 추가할 수 있게 되어 이 제약이 크게 완화됨
- `웹 개발자 관점` : 마치 CRA에서 `npm run eject`를 하는 것과 같음 → but, Expo는 더 유연함
- 실제 사용 : 네이티브 폴더 생성(필요할 때만)
```bash
$ npx expo prebuild
```

### ※ Expo가 적합한 앱 vs. 고려가 필요한 앱
- Expo가 완벽한 경우 (대부분의 앱)
  - 소셜 미디어 앱
  - 이커머스 앱
  - 뉴스/콘텐츠 앱
  - 일정 관리 앱
  - 채팅/메신저 앱
  - 학습/교육 앱

- 고려가 필요한 경우 (드문 케이스)
  - 특정 하드웨어와 직접 통신하는 앱 (예: 의료 기기 제어)
  - 매우 복잡한 3D 게임
  - 기업용 특수 보안 요구사항이 있는 앱
