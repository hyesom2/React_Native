# 2. 대용량 리스트 처리 : `<FlatList>`
- `<ScrollView>`는 모든 콘텐츠를 한 번에 렌더링(그리기)하기 때문에, 아이템의 개수가 많아지면 앱의 성능이 크게 저하됨
- 모바일 앱에서 상품 목록, 채팅 메시지, 뉴스 피드와 같이 **반복되는 대용량 데이터**를 효율적으로 보여주기 위해 React Native는 `<FlatList>`컴포넌트를 제공

---

### 2-1&#41; `<FlatList>`의 핵심 원리 : 가상화 (Virtualization)
- `<FlatList>`의 가장 중요한 특징은 **가상화(Virtualization)**를 통해 성능을 최적화한다는 것
- `<ScrollView>`의 문제 : 화면 밖의 아이템까지 모두 미리 만들어 놓아 메모리 낭비가 심함
- `<FlatList>`의 해결책 : 화면에 **보이는 영역**과 그 주변의 몇몇 아이템만 실제로 렌더링하고, 화면 밖으로 완전히 벗어난 아이템은 **메모리에서 제거**
- `<FlatList>`는 수백, 수천 개의 데이터 목록을 처리하더라도 앱의 메모리 사용량을 최소화하고 부드러운 스크롤 성능을 유지

---

### 2-2&#41; `<FlatList>`의 필수 Props와 사용법
**① `data` (필수)**
- 역할 : 리스트에 표시할 원본 데이터 **배열**

**② `renderItem` (필수)**
- 역할 : `data` 배열의 각 아이템을 화면에 표시할 React 컴포넌트로 변환하는 **함수**

**③ `keyExtractor` (필수 권장)**
- 역할
  - 리스트의 각 아이템에 고유한 **키(Key)**를 지정하는 함수
  - React가 리스트의 아이템이 추가, 제거, 변경될 때 효율적으로 추적할 수 있도록 돕는 매우 중요한 설정
  - 키는 변경되지 않는 고유 값이여야 함&#40;예&#41; 데이터베이스 ID&#41;

```jsx
import React from 'react';
import { FlatList, View, Text, StyleSheet } from 'react-native';

// 1. 표시할 데이터 배열
const dummyData = [
  { id: '1', title: '첫 번째 상품', price: 10000 },
  { id: '2', title: '두 번째 상품', price: 25000 },
  // ... 수백 개의 데이터 ...
  { id: '100', title: '마지막 상품', price: 5000 },
];

const ProductList = () => {

  // 2. 각 아이템을 어떻게 그릴지 정의하는 함수
  const renderProductItem = ({ item }) => (
    // item 객체는 { id: '...', title: '...', price: ... } 형태입니다.
    <View style={styles.itemContainer}>
      <Text style={styles.titleText}>{item.title}</Text>
      <Text style={styles.priceText}>{item.price.toLocaleString()}원</Text>
    </View>
  );

  return (
    <FlatList
      data={dummyData} // 1. 데이터 배열 전달
      renderItem={renderProductItem} // 2. 렌더링 함수 전달
      // 3. 각 아이템의 고유 키를 정의합니다. (id 속성을 키로 사용)
      keyExtractor={item => item.id}

      // 기타 옵션: 스크롤 막대 숨기기
      showsVerticalScrollIndicator={false}
    />
  );
};

const styles = StyleSheet.create({
  itemContainer: {
    padding: 15,
    borderBottomWidth: 1,
    borderBottomColor: '#eee',
    flexDirection: 'row',
    justifyContent: 'space-between',
    alignItems: 'center',
  },
  titleText: {
    fontSize: 16,
  },
  priceText: {
    fontSize: 18,
    fontWeight: 'bold',
    color: '#4682b4',
  }
});

export default ProductList;
```

### 2-3&#41; 새로고침 기능 구현 : `onRefresh`와 `refreshing`
- 대부분의 뉴스 피드나 목록 앱은 사용자가 화면을 아래로 당겨서 **최신 데이터를 가져오는 기능(Pull-to-Refresh)**을 제공
- `<FlatList>`는 이 기능을 위한 전용 Props를 제공

**※ 새로고침 구현 단계**
1. `refreshing` 상태 : 데이터 로딩 중인지 여부를 저장하는 `useState` 상태를 만듦
2. `onRefresh` 함수 : 사용자가 당겼을 때 실행될 함수를 정의하고, 이 함수 안에서 데이터를 다시 가져오는 API 통신(7.1절 참고)을 호출
3. Props 연결 : 이 상태와 함수를 `<FlatList>`에 연결

```jsx
// ... (임포트 및 더미 데이터 정의) ...

function RefreshableList() {
  const [data, setData] = useState(dummyData);
  const [refreshing, setRefreshing] = useState(false); // 1. 새로고침 상태

  // 데이터를 다시 불러오는 함수 (실제로는 API 호출 로직이 들어감)
  const handleRefresh = useCallback(async () => {
    setRefreshing(true); // 새로고침 시작 (로딩 스피너 표시)

    // API 호출 시뮬레이션: 1.5초 대기
    await new Promise(resolve => setTimeout(resolve, 1500));

    // 새로운 데이터 추가 (예시)
    const newId = (data.length + 1).toString();
    const newData = [{ id: newId, title: `새로 추가된 아이템 (${newId})`, price: 99999 }, ...data];

    setData(newData); // 데이터 업데이트
    setRefreshing(false); // 새로고침 완료 (스피너 제거)
  }, [data]);

  return (
    <FlatList
      data={data}
      renderItem={renderItem}
      keyExtractor={item => item.id}

      // 2. 새로고침 관련 Props 설정
      onRefresh={handleRefresh} // 사용자가 당겼을 때 실행할 함수
      refreshing={refreshing} // 현재 새로고침 상태 (true일 때 로딩 스피너가 보임)
    />
  );
}
```
- `onRefresh`와 `refreshing` 두 가지 Props를 설정하면, 사용자가 화면을 아래로 당겼을 때 앱이 자동으로 로딩 스피너를 표시하고(`refreshing: true`), 데이터 통신 후 스피너를 숨기게 됨

### 2-4&#41; 무한 스크롤 구현
- 사용자가 리스트의 끝에 도달하면 자동으로 다음 페이지를 로드

**① 기본 무한 스크롤**
```jsx
import React, { useState, useEffect } from 'react';
import {
  FlatList,
  View,
  Text,
  ActivityIndicator,
  StyleSheet
} from 'react-native';

function InfiniteScrollList() {
  const [data, setData] = useState([]);
  const [page, setPage] = useState(1);
  const [loading, setLoading] = useState(false);
  const [hasMore, setHasMore] = useState(true);

  // 초기 데이터 로드
  useEffect(() => {
    loadMore();
  }, []);

  // 데이터 로드 함수
  const loadMore = async () => {
    if (loading || !hasMore) return;

    setLoading(true);

    try {
      // API 호출 (예시)
      const response = await fetch(
        `https://jsonplaceholder.typicode.com/posts?_page=${page}&_limit=10`
      );
      const newData = await response.json();

      if (newData.length === 0) {
        setHasMore(false);  // 더 이상 데이터 없음
      } else {
        setData(prevData => [...prevData, ...newData]);
        setPage(prevPage => prevPage + 1);
      }
    } catch (error) {
      console.error('로드 실패:', error);
    } finally {
      setLoading(false);
    }
  };

  // 로딩 인디케이터
  const renderFooter = () => {
    if (!loading) return null;

    return (
      <View style={styles.footer}>
        <ActivityIndicator size="large" color="#007AFF" />
        <Text style={styles.footerText}>로딩 중...</Text>
      </View>
    );
  };

  // 빈 리스트 처리
  const renderEmpty = () => (
    <View style={styles.empty}>
      <Text>데이터가 없습니다.</Text>
    </View>
  );

  return (
    <FlatList
      data={data}
      keyExtractor={(item) => item.id.toString()}
      renderItem={({ item }) => (
        <View style={styles.item}>
          <Text style={styles.title}>{item.title}</Text>
          <Text style={styles.body} numberOfLines={2}>{item.body}</Text>
        </View>
      )}

      // 무한 스크롤 설정
      onEndReached={loadMore}
      onEndReachedThreshold={0.5}  // 50% 지점에서 로드

      // 로딩 인디케이터
      ListFooterComponent={renderFooter}

      // 빈 리스트
      ListEmptyComponent={renderEmpty}
    />
  );
}

const styles = StyleSheet.create({
  item: {
    padding: 16,
    backgroundColor: 'white',
    marginVertical: 8,
    marginHorizontal: 16,
    borderRadius: 12,
    shadowColor: '#000',
    shadowOpacity: 0.1,
    shadowRadius: 4,
    elevation: 3,
  },
  title: {
    fontSize: 16,
    fontWeight: 'bold',
    marginBottom: 8,
  },
  body: {
    fontSize: 14,
    color: '#666',
  },
  footer: {
    paddingVertical: 20,
    alignItems: 'center',
  },
  footerText: {
    marginTop: 8,
    color: '#666',
  },
  empty: {
    padding: 40,
    alignItems: 'center',
  }
});

export default InfiniteScrollList;
```

**② memo로 아이템 최적화**
```jsx
import React, { memo } from 'react';

// 아이템 컴포넌트를 memo로 감싸기
const ItemCard = memo(({ item, onPress }) => {
  console.log('렌더링:', item.id);  // 불필요한 렌더링 확인

  return (
    <TouchableOpacity
      style={styles.card}
      onPress={() => onPress(item)}
    >
      <Text style={styles.title}>{item.title}</Text>
      <Text style={styles.description}>{item.description}</Text>
    </TouchableOpacity>
  );
}, (prevProps, nextProps) => {
  // 커스텀 비교 함수
  return prevProps.item.id === nextProps.item.id;
});

function OptimizedList() {
  const [data, setData] = useState([]);

  // useCallback으로 함수 메모이제이션
  const handlePress = useCallback((item) => {
    console.log('Pressed:', item.id);
  }, []);

  const renderItem = useCallback(({ item }) => (
    <ItemCard item={item} onPress={handlePress} />
  ), [handlePress]);

  const keyExtractor = useCallback((item) => item.id.toString(), []);

  return (
    <FlatList
      data={data}
      renderItem={renderItem}
      keyExtractor={keyExtractor}
    />
  );
}
```
