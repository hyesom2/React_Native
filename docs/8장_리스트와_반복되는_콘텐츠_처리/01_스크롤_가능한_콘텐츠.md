# 1. 스크롤 가능한 콘텐츠 : `<ScrollView>`
- 앱의 화면 크기는 제한되어 있지만, 표시해야 할 콘텐츠(텍스트, 이미지 등)가 화면 크기를 벗어날 때가 많음
- 웹 브라우저처럼 모바일 앱에서도 이 문제를 해결하기 위해 화면을 위아래로 움직여(스크롤) 모든 내용을 볼 수 있도록 해야함
- React Native에서는 `<ScrollView>`컴포넌트가 이 역할을 담당

---

### 1-1&#41; `<ScrollView>`란?
- `<ScrollView>`는 React Native에서 스크롤 기능을 제공하는 가장 기본적인 컨테이너 컴포넌트
- **스크롤 가능 영역** : `<ScrollView>`내부에 배치된 모든 컴포넌트는 화면 크기를 벗어나더라도 스크롤을 통해 볼 수 있음
- **수직/수평** : 기본적으로는 수직(위아래) 스크롤을 지원하지만, 설정을 통해 수평(좌우) 스크롤도 가능
- **단일 콘텐츠** : `<ScrollView>`의 가장 중요한 특징은 내부의 모든 콘텐츠를 **하나의 덩어리**로 처리함 → 내부 콘텐츠가 모두 렌더링된 후에 스크롤이 가능

---

### 1-2&#41; `<ScrollView>` 사용법
- 스크롤이 필요하다고 판단되는 모든 내용을 `<ScrollView>`태그 안에 넣기

**① 기본 구조**
```jsx
import React from 'react';
import { ScrollView, Text, View, StyleSheet } from 'react-native';

const LongContent = () => {
  // 20줄의 긴 텍스트를 담을 배열 만들기
  const longTextArray = Array.from({ length: 20 }, (_, i) => `이것은 ${i + 1}번째 줄 텍스트입니다.`);

  return (
    // 1. 전체 콘텐츠를 <ScrollView>로 감싸기
    <ScrollView style={styles.container}>
      {/* 2. <ScrollView> 안에 들어가는 모든 내용이 스크롤 가능해짐 */}
      <View style={styles.header}>
        <Text style={styles.headerText}>스크롤 시작 지점</Text>
      </View>

      {longTextArray.map((text, index) => (
        // 반복되는 긴 내용
        <Text key={index} style={styles.itemText}>{text}</Text>
      ))}

      <View style={styles.footer}>
        <Text style={styles.headerText}>스크롤 끝 지점</Text>
      </View>
    </ScrollView>
  );
};

const styles = StyleSheet.create({
  container: {
    flex: 1, // 화면 전체를 차지하도록
    paddingTop: 40,
    paddingHorizontal: 20,
  },
  header: {
    backgroundColor: '#f0f0f0',
    padding: 10,
    marginBottom: 10,
  },
  headerText: {
    fontSize: 20,
    fontWeight: 'bold',
  },
  itemText: {
    fontSize: 16,
    paddingVertical: 8,
    borderBottomWidth: 1,
    borderBottomColor: '#eee',
  },
  footer: {
    backgroundColor: '#f0f0f0',
    padding: 10,
    marginTop: 10,
    marginBottom: 30, // 맨 아래까지 스크롤이 잘 되도록 여백주기
  }
});

export default LongContent;
```

**② 수평 스크롤 (가로 스크롤)**
- 기본값 : 수직 스크롤
- `horizontal` props를 `true`로 설정 → 가로로 스크롤되는 콘텐츠
- 예&#41; 상품 상세 페이지의 작은 이미지 갤러리

```jsx
// 수평 스크롤이 필요한 부분에
<ScrollView horizontal={true} showsHorizontalScrollIndicator={false}>
  {/* 가로로 나열될 콘텐츠 (예: 이미지 컴포넌트들) */}
  <View style={styles.horizontalItem} />
  <View style={styles.horizontalItem} />
  {/* ... */}
</ScrollView>
```

### 1-3&#41; `<ScrollView>` 사용 시 주의할 점 (성능 문제)
- `<ScrollView>`는 간단한 구조를 가질 때 사용하기 좋지만, **매우 많은 양의 데이터(예: 100개 이상의 아이템)**를 표시할 때는 **성능 문제가 발생**

**① `<ScrollView>`의 한계**
- `<ScrollView>`는 내부에 있는 모든 컴포넌트들을 **화면에 보이지 않더라도** 앱이 실행되는 순간 **미리 다 렌더링**해서 메모리에 로드함
- **문제점** : 아이템이 수백 개가 되면, 앱 시작 시간이 길어지고 메모리를 많이 소모하여 앱이 느려지거나 멈출 수 있음

**② 해결책 : `<FlatList>` 사용**
- 콘텐츠의 양이 적거나 내용이 정적일 때(예: 긴 글 한 편, 앱 설정 목록)는 `<ScrollView>`가 적합함
- 하지만 반복되는 목록 데이터가 많거나 **데이터의 양이 가변적일 때**는 `<FlatList>`를 사용
- `<FlatList>`는 화면에 보이는 아이템만 그때그때 만들고, 지나간 아이템은 메모리에서 해제하여 성능을 최적화

### 1-4&#41; ScrollView 주요 Props
**① 스크롤 제어**
```jsx
<ScrollView
  // 스크롤 방향
  horizontal={false}  // true: 가로, false: 세로 (기본값)

  // 스크롤 인디케이터 표시 여부
  showsVerticalScrollIndicator={true}    // 세로 스크롤바
  showsHorizontalScrollIndicator={true}  // 가로 스크롤바

  // 스크롤 가능 여부
  scrollEnabled={true}  // false로 설정하면 스크롤 비활성화

  // 페이지 스크롤 (카드 넘기듯이)
  pagingEnabled={false}  // true: 페이지 단위로 스크롤

  // 튕기기 효과 (iOS)
  bounces={true}  // false: 끝에서 튕기지 않음

  // 스크롤 위치 고정
  scrollsToTop={true}  // iOS: 상태바 탭 시 맨 위로
>
  {/* 콘텐츠 */}
</ScrollView>
```

**②  콘텐츠 스타일링**
```jsx
<ScrollView
  // 콘텐츠 컨테이너 스타일
  contentContainerStyle={{
    padding: 16,
    paddingBottom: 100,  // 하단 여백
  }}

  // 스크롤뷰 자체 스타일
  style={{
    flex: 1,
    backgroundColor: '#f5f5f5'
  }}
>
  {/* 콘텐츠 */}
</ScrollView>
```

**③ 스크롤 이벤트**
```jsx
function ScrollExample() {
  const scrollY = useRef(0);

  return (
    <ScrollView
      onScroll={(event) => {
        // 스크롤 위치 추적
        scrollY.current = event.nativeEvent.contentOffset.y;
        console.log('스크롤 위치:', scrollY.current);
      }}
      scrollEventThrottle={16}  // 스크롤 이벤트 빈도 (ms)

      onScrollBeginDrag={() => {
        console.log('스크롤 시작');
      }}

      onScrollEndDrag={() => {
        console.log('스크롤 끝');
      }}
    >
      {/* 콘텐츠 */}
    </ScrollView>
  );
}
```
