# 4. 로컬 데이터 저장 : AsyncStorage (Expo/React Native) 사용법
- API 통신을 통해 서버에서 데이터를 가져오는 것은 중요하지만, 매번 앱을 실행할 때마다 혹은 화면을 이동할 때마다 데이터를 다시 요청하는 것은 **비효율**
- **로컬 저장소(Local Storage)**에 데이터를 저장해 두면, 인터넷 연결 없이도 데이터를 빠르게 읽어와 사용할 수 있음
- React Native에서는 로컬 저장소 기능을 위해 **AsyncStorage**를 사용

---

### 4-1&#41; AsyncStorage란?
- **AsyncStorage**는 React Native 앱의 **사용자 기기 내부**에 데이터를 비동기적으로(Asynchronously) 저장할 수 있도록 해주는 간단한 키-값(Key-Value) 기반의 저장 시스템
- **키-값 저장소** : 웹의 `localStorage`와 유사하게, 데이터를 저장할 때 **고유한 이름(키)**과 **저장할 실제 값(값)** 을 쌍으로 사용
- **비동기(Async)** : 데이터 저장 및 읽기 작업은 시간이 걸릴 수 있으므로, 앱이 멈추지 않도록 **비동기 방식**으로 처리 → `async/await`를 함께 사용
- **용도** : 사용자 설정(테마, 알림 설정), 로그인 토큰(Token), 마지막으로 본 화면 위치, 간단한 캐시 데이터 등을 저장하는 데 적합함
- **제약** : 대용량의 구조화된 데이터(데이터베이스 수준)를 저장하는 데는 적합하지 않습니다. (이 경우 SQLite나 다른 데이터베이스 솔루션을 고려해야 합니다.)

### 4-2&#41; AsyncStorage 설치 및 사용 준비
- Expo 환경에서는 별도의 복잡한 네이티브 설정 없이 간단하게 설치

**① 패키지 설치**
```bash
npx expo install @react-native-async-storage/async-storage
```

**② 임포트**
- 사용할 파일 상단에서 `AsyncStorage` 객체를 임포트

```jsx
import AsyncStorage from '@react-native-async-storage/async-storage';
```

### 4-3&#41; 데이터 저장 및 읽기 (핵심 기능)
- AsyncStorage의 기본적인 사용법은 데이터를 저장하는 `setItem`과 읽어오는 `getItem` 두 가지

**① 데이터 저장 : `AsyncStorage.setItem(key, value)`**
- 데이터를 문자열(String) 형태로 저장
- 만약 객체나 배열을 저장하려면 반드시 **JSON 문자열**로 변환해야함

```jsx
const saveUserData = async (key, value) => {
  try {
    // 객체를 저장하려면 반드시 JSON.stringify()로 문자열화 해야함
    const jsonValue = JSON.stringify(value);

    // 'user_data'라는 키로 JSON 문자열을 저장
    await AsyncStorage.setItem(key, jsonValue); 
    console.log(`데이터 저장 성공: 키 ${key}`);
  } catch (e) {
    console.error("데이터 저장 실패:", e);
  }
};

// 예시: 사용자 설정 객체 저장
const userSettings = { theme: 'dark', notifications: true };
saveUserData('app_settings', userSettings);
```

**② 데이터 읽기 : `AsyncStorage.getItem(key)`**
- 저장된 키를 사용하여 데이터를 읽어옴
- 데이터가 없으면 `null`을 반환
- 읽어온 데이터는 항상 **문자열**이므로, 객체였던 데이터는 다시 객체로 변환해야함

```jsx
const getUserData = async (key) => {
  try {
    // 저장된 문자열 값을 읽어오기
    const jsonValue = await AsyncStorage.getItem(key);

    if (jsonValue !== null) {
      // 읽어온 JSON 문자열을 다시 JavaScript 객체로 변환하기
      const dataObject = JSON.parse(jsonValue);
      console.log(`데이터 로드 성공: 키 ${key}`, dataObject);
      return dataObject;
    } else {
      console.log(`저장된 데이터 없음: 키 ${key}`);
      return null;
    }
  } catch (e) {
    console.error("데이터 로드 실패:", e);
  }
};

// 예시: 저장된 설정 데이터 읽어오기
getUserData('app_settings');
```

**③ 데이터 삭제: `AsyncStorage.removeItem(key)`**
- 특정 키에 저장된 데이터를 삭제
```jsx
const removeData = async (key) => {
  try {
    await AsyncStorage.removeItem(key);
    console.log(`데이터 삭제 성공: 키 ${key}`);
  } catch (e) {
    console.error("데이터 삭제 실패:", e);
  }
};

// 예시: 로그인 토큰 삭제
removeData('user_token');
```

### 4-4&#41; AsyncStorage 고급 활용
**① 여러 항목 한 번에 저장/읽기**
```jsx
// 여러 항목 저장
const multiSet = async () => {
  try {
    await AsyncStorage.multiSet([
      ['username', 'john'],
      ['email', 'john@example.com'],
      ['theme', 'dark']
    ]);
  } catch (error) {
    console.error('저장 오류:', error);
  }
};

// 여러 항목 읽기
const multiGet = async () => {
  try {
    const values = await AsyncStorage.multiGet(['username', 'email', 'theme']);
    console.log(values);
    // [['username', 'john'], ['email', 'john@example.com'], ['theme', 'dark']]
  } catch (error) {
    console.error('읽기 오류:', error);
  }
};
```

**② 모든 키 가져오기**
```jsx
const getAllKeys = async () => {
  try {
    const keys = await AsyncStorage.getAllKeys();
    console.log('저장된 키들:', keys);
  } catch (error) {
    console.error('키 조회 오류:', error);
  }
};
```

**③ 전체 데이터 삭제**
```jsx
const clearAll = async () => {
  try {
    await AsyncStorage.clear();
    console.log('모든 데이터 삭제 완료');
  } catch (error) {
    console.error('삭제 오류:', error);
  }
};
```

### 4-5&#41; 실전 활용 : 데이터 로딩 최적화
- AsyncStorage는 `useEffect` Hook과 함께 사용되어 앱 시작 시 저장된 데이터를 로드하는 데 유용함

```jsx
import React, { useState, useEffect } from 'react';
import { View, Text, Button } from 'react-native';
import AsyncStorage from '@react-native-async-storage/async-storage';

function LocalStorageScreen() {
  const [theme, setTheme] = useState('light');

  // 1. 앱 시작 시 저장된 테마 불러오기 (읽기)
  useEffect(() => {
    const loadTheme = async () => {
      const storedTheme = await AsyncStorage.getItem('user_theme');
      if (storedTheme) {
        setTheme(storedTheme);
      }
    };
    loadTheme();
  }, []);

  // 2. 버튼 클릭 시 테마 변경 및 저장 (쓰기)
  const toggleTheme = async () => {
    const newTheme = theme === 'light' ? 'dark' : 'light';
    setTheme(newTheme);

    try {
      // 새로운 테마 값을 AsyncStorage에 저장
      await AsyncStorage.setItem('user_theme', newTheme);
      console.log(`테마가 ${newTheme}로 저장되었습니다.`);
    } catch (e) {
      console.error("테마 저장 오류:", e);
    }
  };

  return (
    <View style={{ flex: 1, backgroundColor: theme === 'dark' ? '#333' : '#fff', justifyContent: 'center', alignItems: 'center' }}>
      <Text style={{ color: theme === 'dark' ? '#fff' : '#000', fontSize: 20, marginBottom: 20 }}>
        현재 테마: {theme}
      </Text>
      <Button title="테마 토글 (저장)" onPress={toggleTheme} />
    </View>
  );
}

export default LocalStorageScreen;
```
