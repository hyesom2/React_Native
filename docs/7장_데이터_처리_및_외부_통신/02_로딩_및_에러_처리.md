# 2. 로딩 및 에러 처리 : 사용자 경험과 안정성 확보
- API 통신을 할 때, 데이터가 즉시 도착하는 경우는 없으며, 서버에 요청을 보내고 응답을 기다리는 동안 시간이 소요됨
- 네트워크 상태가 불안정하거나 서버에 문제가 생기면 데이터 요청이 실패할 수 있음
- **로딩(Loading) 처리**와 **에러(Error) 처리**는 앱이 멈추거나 깨지는 것을 방지하고, 사용자에게 현재 상황을 명확하게 알려주는 **사용자 경험(UX)**의 필수 요소

---

### 2-1&#41; 로딩 처리 : 대기 상태 알림
- 데이터를 가져오는 동안 사용자가 앱이 멈춘 것으로 오해하지 않도록, 현재 작업이 진행 중임을 알려야 함

**① `useState`로 로딩 상태 관리**
- 가장 기본적인 방법은 React의 `useState` Hook을 사용하여 데이터 로딩 상태를 참(`true`) 또는 거짓(`false`)으로 관리하는 것
- 앱이 데이터를 가져오기 **시작**할 때: `setLoading(true)`
- 앱이 데이터를 가져오기를 **완료**하거나 **실패**했을 때: `setLoading(false)`

**② `<ActivityIndicator>` 컴포넌트 사용**
- React Native는 로딩 중임을 시각적으로 보여주는 네이티브 컴포넌트인 `<ActivityIndicator>`를 제공
- 이것은 iOS의 스피너(Spinner)나 Android의 프로그레스 바(Progress Bar)와 같은 역할을 함

```jsx
import { View, Text, ActivityIndicator, StyleSheet } from 'react-native';
// ... (useState, useEffect 등의 훅 임포트)

function DataScreen() {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true); // 초기 상태는 로딩 중(true)

  // ... fetch 함수 (7.1절 참고) ...
  const fetchData = async () => {
    try {
      // API 통신 시작 전: 이미 true이지만 명시적으로 두는 경우도 있음
      const response = await fetch('...');
      const json = await response.json();
      setData(json);
    } catch (error) {
      // 에러 처리 부분 (7.2.2절에서 상세 설명)
      console.error(error); 
    } finally {
      setLoading(false); // 성공/실패와 관계없이 통신이 끝나면 로딩 상태 해제
    }
  };
  // ... (useEffect를 이용한 fetchData 호출) ...

  // 3. 조건부 렌더링: loading 상태에 따라 다른 UI를 보여줍니다.
  if (loading) {
    return (
      <View style={styles.centerContainer}>
        {/* ActivityIndicator: 로딩 애니메이션 */}
        <ActivityIndicator size="large" color="#0000ff" /> 
        <Text style={styles.message}>데이터를 불러오는 중입니다...</Text>
      </View>
    );
  }

  // 로딩이 false이고 데이터가 있을 때만 실제 데이터 화면을 보여줍니다.
  return (
    <View style={styles.container}>
      <Text>{data.title}</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  centerContainer: { flex: 1, justifyContent: 'center', alignItems: 'center' },
  // ...
});
```

### 2-2&#41; 에러 처리 : 실패 상황 안내
- API 통신은 다양한 이유(네트워크 끊김, URL 오타, 서버 다운, 잘못된 요청 등)로 실패할 수 있음
- 에러 처리는 **앱이 오류로 인해 완전히 중단(Crash)되는 것을 방지**하고, 사용자에게 **무엇이 잘못되었는지 알려주어** 재시도 기회를 제공

**① `try...catch...finally` 블록 활용**
- 비동기 통신 코드를 `try` 블록 안에 넣고, 오류가 발생했을 때 처리할 코드를 `catch` 블록 안에 넣어 안정성을 확보

```jsx
// ... (useState 임포트)

function ErrorHandlingScreen() {
  const [errorMsg, setErrorMsg] = useState(null); // 에러 메시지를 담을 상태
  const [data, setData] = useState(null);

  const fetchData = async () => {
    try {
      setErrorMsg(null); // 새 요청 시작 시 이전 에러 메시지 초기화
      const response = await fetch('잘못된_URL_예시'); // 일부러 잘못된 URL을 호출

      if (!response.ok) {
         // HTTP 상태 코드가 200번대가 아닐 경우 (예: 404, 500 등)
         throw new Error(`서버 응답 오류: ${response.status}`);
      }

      const json = await response.json();
      setData(json);
    } catch (error) {
      // 네트워크 오류, JSON 파싱 오류 등 실제 오류가 발생했을 때
      console.error("API 통신 실패:", error.message);
      setErrorMsg(`데이터를 가져오는 데 실패했습니다: ${error.message}`);
    } finally {
      // setLoading(false);
    }
  };

  // 2. 에러가 있을 때 사용자에게 메시지를 보여줍니다.
  if (errorMsg) {
    return (
      <View style={styles.centerContainer}>
        <Text style={styles.errorMessage}>오류 발생!</Text>
        <Text>{errorMsg}</Text>
        <Button title="다시 시도" onPress={fetchData} />
      </View>
    );
  }

  // ... (로딩 또는 데이터 표시) ...
}
```

**② 에러 처리의 세 가지 경우**

| 에러 유형	| 발생 시점 | 처리 방법 |
| :--: | :-- | :-- |
| **네트워크 오류** |	`fetch()` 요청 자체를 보내지 못했을 때 | `try...catch` 블록에서 `catch (error)`로 잡힘 (네트워크 끊김, 서버 연결 불가 등) |
| **HTTP 오류** | `fetch()` 요청은 성공했으나 응답 코드가 200번대가 아닐 때	| `response` 객체의 `ok`속성을 확인하여 `false`일 경우, 개발자가 **강제**로 `throw new Error()`를 발생시켜 `catch` 블록으로 넘김 |
| JSON 파싱 오류 | 응답 데이터가 JSON 형식이 아닐 때 | `await response.json()` 부분에서 오류가 발생하며 `catch (error)`로 잡힘 |

**② Pull to Refresh (당겨서 새로고침)**
```jsx
import { RefreshControl } from 'react-native';

function PostsList() {
  const [posts, setPosts] = useState([]);
  const [refreshing, setRefreshing] = useState(false);

  const onRefresh = async () => {
    setRefreshing(true);
    await fetchPosts();
    setRefreshing(false);
  };

  return (
    <FlatList
      data={posts}
      refreshControl={
        <RefreshControl
          refreshing={refreshing}
          onRefresh={onRefresh}
          colors={['#007AFF']}  // Android
          tintColor="#007AFF"    // iOS
        />
      }
      renderItem={({ item }) => <PostCard post={item} />}
    />
  );
}
```
