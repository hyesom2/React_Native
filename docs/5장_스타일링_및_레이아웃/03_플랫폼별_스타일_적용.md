# 3. 플랫폼별 스타일 적용
- React Native는 하나의 코드로 iOS와 Android 모두에서 실행되지만, 두 운영체제(OS)는 디자인 가이드라인, UI 요소의 모양, 그리고 애니메이션 방식이 서로 다름
- 완벽한 모바일 앱을 만들려면 각 플랫폼의 특징을 살린 맞춤형 스타일을 적용
- React Native는 이 플랫폼별 차이를 쉽게 처리할 수 있도록 두 가지 주요 API를 제공

---

### 3-1&#41; `Platform` API : OS 별 코드 분기
- `Platform` API는 현재 앱이 실행되고 있는 운영체제(iOS, Android, Web 등)를 확인하여, 코드 실행을 다르게 하거나 스타일을 조건부로 적용할 수 있음

**① `Platform.OS` 사용 (조건부 스타일)**
- 가장 흔한 사용법은 특정 스타일 속성만 OS에 따라 다르게 지정하는 것

```jsx
import { Platform, StyleSheet, View, Text } from 'react-native';

const styles = StyleSheet.create({
  header: {
    paddingTop: 10,
    backgroundColor: 'white',

    // iOS일 경우 패딩을 20으로, 아닐 경우(Android) 10으로 설정
    paddingHorizontal: Platform.OS === 'ios' ? 20 : 10,

    // iOS는 그림자, Android는 입체 효과(elevation) 사용
    ...Platform.select({
      ios: {
        shadowColor: 'black',
        shadowOpacity: 0.2,
        shadowRadius: 3,
      },
      android: {
        elevation: 5,
      },
      default: { // 웹이나 다른 플랫폼
        // 기본 스타일
      }
    }),
  },
  title: {
    // Android는 세리프 폰트, iOS는 시스템 기본 폰트
    fontFamily: Platform.OS === 'android' ? 'sans-serif' : 'System',
    fontSize: 18,
  }
});

function CustomHeader() {
  // ...
  return (
    <View style={styles.header}>
      <Text style={styles.title}>앱 제목</Text>
    </View>
  );
}
```
- `Platform.OS`
  - `'ios'`, `'android'`, `'web'` 등의 문자열 값을 반환
- `Platform.select({})`
  - 객체를 인수로 받아 현재 OS에 해당하는 키(`ios` 또는 `android`)의 값을 반환
  - 스타일 객체 내에서 여러 속성을 한 번에 지정할 때 매우 유용

**② `Platform.Version` 사용 (OS 버전별 코드)**
- 특정 OS 버전 이상에서만 지원되는 기능을 사용하거나 버그를 회피하기 위해 `Platform.Version`을 사용

```jsx
// Android API 21 버전(Android 5.0) 이상에서만 투명한 상태 표시줄 사용
if (Platform.OS === 'android' && Platform.Version >= 21) {
  // 특정 기능 활성화 코드
}
```
- **iOS** : OS 버전 번호(예: `17`)를 반환
- **Android** : API 레벨(예: `34`)을 반환

### 3-2&#41; 플랫폼별 파일 확장자 (Component-Specific Files)
- 스타일뿐만 아니라, 컴포넌트 전체를 OS에 따라 다르게 구현해야 할 때가 있음
- 예&#41; iOS 전용으로 복잡한 네비게이션 헤더를 만들 때
- React Native는 파일 이름에 `.ios` 또는 `.android` 확장자를 붙이면, 실행 환경에 따라 **자동으로 해당 파일을 불러오는** 기능을 지원

**※ 작동 원리**
1. 프로젝트에 두 개의 파일이 존재
- `CustomButton.js`(기본 파일)
- `CustomButton.ios.js`(iOS 전용 파일)
- `CustomButton.android.js`(Android 전용 파일)

2. 다른 파일에서 CustomButton을 임포트하면 : JavaScript <br />
`import CustomButton from './CustomButton';`
- **iOS 환경** : 자동으로 `CustomButton.ios.js` 파일을 가져와 실행
- **Android 환경** : 자동으로 `CustomButton.android.js`파일을 가져와 실행
- **웹 환경** : `.ios`나 `.android`확장자가 없는 `CustomButton.js` 파일을 가져옴

**※ 파일 분할 예시**
- `CustomButton.ios.js`
```jsx
import React from 'react';
import { Button } from 'react-native';

// iOS의 네이티브 버튼을 사용하는 iOS 전용 컴포넌트
export default function CustomButton({ onPress, title }) {
  return <Button title={title} onPress={onPress} color="#007AFF" />;
}
```

- `CustomButton.android.js`
```jsx
import React from 'react';
import { Pressable, Text, StyleSheet } from 'react-native';

// Pressable을 사용하여 Material Design 느낌을 살린 Android 전용 컴포넌트
export default function CustomButton({ onPress, title }) {
  return (
    <Pressable style={styles.androidButton} onPress={onPress} android_ripple={{ color: '#333' }}>
      <Text style={styles.text}>{title}</Text>
    </Pressable>
  );
}

const styles = StyleSheet.create({
    androidButton: {
        backgroundColor: '#6200EE',
        paddingVertical: 10,
        paddingHorizontal: 15,
        borderRadius: 2,
    },
    text: {
        color: 'white',
        fontWeight: 'bold',
    }
});
```
