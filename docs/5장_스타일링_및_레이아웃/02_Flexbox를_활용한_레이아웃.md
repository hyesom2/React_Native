# 2. Flexbox를 활용한 레이아웃

### 2-1&#41; Flexbox의 핵심 용어 이해
- Flexbox 시스템은 **컨테이너(Container)**와 그 안에 있는 **아이템(Item)**이라는 두 가지 관계를 기반으로 작동
1. **컨테이너 (부모)**
- 자식 아이템들을 담고 있는 `<View>`컴포넌트
- 여기에 Flexbox 스타일 속성을 적용하여 아이템들의 배치를 결정
2. **아이템 (자식)**
- 컨테이너 안에 배치되는 `<Text>`, `<Button>`, 다른 `<View>`등의 컴포넌트

**※ Flexbox는 두 가지 주요 축을 기준으로 작동**
- **주축 (Main Axis)** : 아이템들이 나열되는 주된 방향(`flexDirection`으로 결정)
- **교차축 (Cross Axis)** : 주축에 수직인 방향

---

### 2-2&#41; 부모(컨테이너)에 적용하는 핵심 속성
- 부모 `<View>`에 스타일을 적용하여 모든 자식 아이템의 배치를 제어

**① `flexDirection` : 주축 방향 설정 (가장 중요)**
- React Native의 Flexbox에서 **가장 중요한 차이점**
- Flexbox는 자식 아이템들이 나열되는 주축의 방향을 결정

| **속성값** | **설명** | 배치 방향 |
| :--: | :--: | :--: |
| `column` | 아이템을 위에서 아래로 **세로**로 나열 | **React Native의 기본값** |
| `row`	| 아이템을 왼쪽에서 오른쪽으로 **가로**로 나열 | 웹 CSS의 기본값 |

```jsx
// 자식들을 가로로 나열하고 싶다면 반드시 row로 설정
parentStyle: {
  flexDirection: 'row', 
}
```

**② `justifyContent` : 주축 정렬**
**주축 방향**으로 아이템들이나 아이템들 사이의 공간을 어떻게 배치할지 결정

| **속성값** | **설명** | 
| :--: | :-- |
| `flex-start` | 주축 시작점에 모아서 정렬 |
| `center` | 주축 중앙에 정렬 |
| `flex-end` | 주축 끝점에 모아서 정렬 |
| `space-between` | 아이템들 사이에 균등한 공간을 분배 (가장자리에는 공간 없음) |
| `space-around` | 모든 아이템 주변에 균등한 공간을 분배 (가장자리에도 공간 있음) |

**③ `alignItems` : 교차축 정렬**

| **속성값** | **설명** | 
| :--: | :-- |
| `flex-start` | 교차축 시작점에 모아서 정렬 |
| `center` | 교차축 중앙에 정렬 |
| `flex-end` | 교차축 끝점에 모아서 정렬 |
| `stretch` | 아이템이 교차축을 가득 채우도록 늘어남 (아이템에 `width`나 `height`가 지정되지 않았을 때 작동) |

### 2-3&#41; 자식(아이템)에 적용하는 핵심 속성
- 자식 `<View>`에 스타일을 적용하여 부모 공간 내에서 해당 아이템이 차지하는 비율이나 정렬을 제어

**① `flex` : 공간 분배 비율 설정 (가장 중요)**
- flex 속성은 해당 아이템이 부모 컨테이너의 남은 공간을 얼마나 차지할지 **비율**로 지정
- `flex: 1` : 아이템이 부모의 **남은 공간을 모두 차지**하도록 늘어남 (화면 전체 채우기의 기본 공식)
- `flex: N` : 여러 아이템에 `flex`값이 지정되면, N 값의 비율대로 남은 공간을 나누어 가짐

```jsx
// 부모 컨테이너에 flexDirection: 'row'가 적용되어 있다고 가정
<View style={{ flex: 1, backgroundColor: 'red' }} />  // 1/3 공간 차지
<View style={{ flex: 2, backgroundColor: 'blue' }} /> // 2/3 공간 차지 (1의 두 배)
```

**③ `alignSelf` : 나만 다르게 정렬**
- `alignSelf`는 부모의 `alignItems`설정을 무시하고 **특정 아이템 하나만** 교차축에서 다르게 정렬하고 싶을 때 사용
- 값은 `alignItems`와 동일(`center`, `flex-start`, `flex-end`, `stretch`)

```jsx
// 부모는 alignItems: 'flex-start' 이지만, 이 아이템만 중앙으로 정렬
<View style={{ alignSelf: 'center' }} />
```
