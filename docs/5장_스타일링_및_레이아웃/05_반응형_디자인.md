# 5. 반응형 디자인

### 5-1&#41; Dimensions API
- Dimensions API는 현재 기기의 화면 크기를 가져올 수 있게 함

```jsx
import { Dimensions } from 'react-native';

// 화면 크기 가져오기
const windowWidth = Dimensions.get('window').width;
const windowHeight = Dimensions.get('window').height;

// 전체 화면 크기 (상태바 포함)
const screenWidth = Dimensions.get('screen').width;
const screenHeight = Dimensions.get('screen').height;

console.log('화면 너비:', windowWidth);
console.log('화면 높이:', windowHeight);
```

### 5-2&#41; 비율 기반 레이아웃
- 고정 크기 대신 비율(%)을 사용하면 모든 화면에서 일관된 레이아웃을 유지 가능

```jsx
import { Dimensions, StyleSheet } from 'react-native';

const { width, height } = Dimensions.get('window');

const styles = StyleSheet.create({
  // 화면 너비의 90%
  container: {
    width: width * 0.9,
    alignSelf: 'center',
  },

  // 정사각형 (화면 너비의 40%)
  square: {
    width: width * 0.4,
    height: width * 0.4,
  },

  // 화면 높이의 30%
  section: {
    height: height * 0.3,
  },

  // 반응형 폰트 크기
  title: {
    fontSize: width * 0.06,  // 화면 너비의 6%
  }
});
```

### 5-3&#41; useWindowDimensions Hook
- 화면 회전에 자동으로 반응하는 최신 방법

```jsx
import { useWindowDimensions, View, Text } from 'react-native';

function ResponsiveComponent() {
  const { width, height, scale, fontScale } = useWindowDimensions();

  // 방향 감지
  const isPortrait = height > width;
  const isLandscape = width > height;

  return (
    <View style={{
      width: width * 0.9,
      padding: width * 0.05,
    }}>
      <Text style={{ fontSize: width * 0.05 }}>
        화면 너비: {width.toFixed(0)}
      </Text>
      <Text>
        방향: {isPortrait ? '세로' : '가로'}
      </Text>
    </View>
  );
}
```

### 5-4&#41; 브레이크포인트 시스템

```jsx
// utils/responsive.js
import { Dimensions } from 'react-native';

export const getBreakpoint = () => {
  const { width } = Dimensions.get('window');

  if (width < 480) return 'xs';      // 작은 폰
  if (width < 768) return 'sm';      // 일반 폰
  if (width < 1024) return 'md';     // 큰 폰/작은 태블릿
  if (width < 1280) return 'lg';     // 태블릿
  return 'xl';                        // 큰 태블릿
};

export const isTablet = () => {
  const { width } = Dimensions.get('window');
  return width >= 768;
};

export const responsive = (xs, sm, md, lg, xl) => {
  const breakpoint = getBreakpoint();
  const sizes = { xs, sm, md, lg, xl };
  return sizes[breakpoint] || xs;
};

// 사용 예시
function AdaptiveLayout() {
  const columns = responsive(2, 3, 4, 5, 6);
  const fontSize = responsive(14, 16, 18, 20, 22);
  const padding = responsive(8, 12, 16, 20, 24);

  return (
    <View style={{ padding }}>
      <Text style={{ fontSize }}>반응형 텍스트</Text>
      <FlatList numColumns={columns} />
    </View>
  );
}
```

### ※ 반응형 디자인 팁
**Tip 1 : 고정 크기보다 비율 사용**
```jsx
// 고정 크기
width: 300

// 비율
width: '80%'
// 또는
width: Dimensions.get('window').width * 0.8
```

**Tip 2 : 최소/최대 크기 제한**
```jsx
const { width } = useWindowDimensions();
const cardWidth = Math.min(Math.max(width * 0.4, 150), 300);
// 최소 150, 최대 300
```

**Tip 3 : 방향 전환 대응**
```jsx
const { width, height } = useWindowDimensions();
const isLandscape = width > height;

<View style={{
  flexDirection: isLandscape ? 'row' : 'column'
}}>
  {/* 가로 모드에서는 가로 배치, 세로 모드에서는 세로 배치 */}
</View>
```
