# 2. Expo GO 설치 및 시뮬레이터

### 2-1&#41; Expo Go: 가장 빠르고 쉬운 방법 (실제 스마트폰 테스트)
- Expo Go는 여러분의 실제 스마트폰을 사용하여 개발 중인 앱을 테스트할 수 있게 해주는 필수 모바일 앱
- React Native 개발을 시작하는 가장 빠르고 편리한 방법

### ※ Expo Go의 작동 원리
- Expo Go 앱은 iOS와 Android의 네이티브 환경(JavaScript 실행 엔진, 기본 UI 컴포넌트, 카메라/GPS 접근 권한 등)이 미리 구현된 `범용 컨테이너` 역할
1. 개발 서버에서 작성한 JavaScript 코드를 무선 네트워크를 통해 스마트폰의 Expo Go 앱으로 전송
2. Expo Go 앱이 이 코드를 받아 네이티브 기능을 호출하면서 앱을 실행

### ※ 설치 방법
- `iOS (iPhone/iPad)` : Apple App Store에서 `Expo Go`를 검색하여 설치
- `Android (갤럭시/LG 등)`: Google Play Store에서 `Expo Go`를 검색하여 설치
- 장점
1. **설정 불필요** : 복잡한 개발 도구(Xcode, Android Studio)를 설치할 필요없음
2. **실시간 확인** : 코드를 저장하는 즉시 앱 화면이 업데이트(`Fast Refresh`)
3. **실제 기기 테스트** : 화면 크기, 터치감, 카메라 등 실제 기기에서 앱이 어떻게 보이는지 가장 정확하게 확인가능

### ※ Expo Go 사용 시 자주 발생하는 문제
- 문제 1 : QR 코드를 스캔했는데 앱이 로드되지 않음
  - 원인 : 컴퓨터와 스마트폰이 같은 Wi-Fi 네트워크에 연결되어 있지 않음
  - 해결
  1. 컴퓨터와 스마트폰이 동일한 Wi-Fi에 연결되어 있는지 확인
  2. 회사나 학교의 네트워크는 기기 간 통신을 막을 수 있음 → 개인 Wi-Fi를 사용
  3. 그래도 안 되면 Tunnel 모드를 사용
  ```
  npx expo start --tunnel
  ```
- 문제 2 : "네트워크 응답이 없습니다" 오류
  - 원인 : 방화벽이나 백신 프로그램이 Expo 서버를 차단하고 있을 수 있음
  - 해결 : 방화벽 설정에서 Expo와 Node.js를 허용 목록에 추가

- 문제 3 : 앱이 "Uncaught Error" 또는 빨간 화면이 나타남
  - 원인 : 코드에 문법 오류가 있거나 존재하지 않는 컴포넌트/변수를 사용함
  - 해결
  1. 오류 메시지를 자세히 읽어보세요. 어느 파일의 몇 번째 줄에 오류가 있는지 알려줌
  2. VS Code에서 해당 파일을 열고 오류를 수정
  3. 파일을 저장하면 자동으로 앱이 다시 로드됨

- 문제 4: 업데이트가 반영되지 않습니다 (Fast Refresh 실패)
  - 해결
  1. Expo Go 앱에서 흔들기 제스처 (스마트폰을 흔들면 개발자 메뉴가 나타남) 
  2. "Reload" 버튼을 누르기
  3. 또는 터미널에서 r 키를 눌러 수동으로 새로고침

### ※ Expo Go 개발자 메뉴 활용하기
- 스마트폰을 흔들면 (또는 Android는 3손가락 터치) Expo Go 개발자 메뉴가 나타남
- **유용한 메뉴 옵션**
1. Reload - 앱 전체를 다시 로드
2. Go Home - Expo Go 홈 화면으로 돌아가기
3. Enable/Disable Fast Refresh - 자동 새로고침 토글
4. Show Performance Monitor - 성능 모니터 표시 (FPS, 메모리 사용량)
5. Toggle Element Inspector - 화면의 요소를 터치하여 스타일 정보 확인

### ※ Expo Go를 더 효과적으로 사용하는 팁
1. 여러 프로젝트를 빠르게 전환하기 Expo Go 앱 하단의 "Recently opened" 섹션에서 최근에 열었던 프로젝트들을 빠르게 다시 열 수 있음
2. 오프라인에서도 개발하기 한 번 프로젝트를 로드하면, Wi-Fi가 끊겨도 이미 로드된 코드는 계속 작동함. 단, 새로운 변경사항은 동기화되지 않음
3. 여러 기기에서 동시에 테스트하기 같은 네트워크에 있는 여러 스마트폰(친구 것, 태블릿 등)에서 동시에 같은 QR 코드를 스캔하여 다양한 화면 크기에서 테스트할 수 있음
