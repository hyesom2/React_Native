### 2-1&#41; Node.js : 자바스크립트 실행 환경
- `Node.js`는 React Native를 포함한 현대적인 자바스크립트(JavaScript) 기반 개발에서 가장 필수적인 도구

### ※ Node.js의 역할
- Node.js는 웹 브라우저 밖에서도 자바스크립트 코드를 실행할 수 있게 해주는 `실행 환경(Runtime Environment)`
- `Expo CLI`실행 : React Native 프로젝트를 만들고 실행하는 명령줄 도구(CLI)가 Node.js 환경에서 작동
- `패키지 관리` : 앱 개발에 필요한 수많은 외부 라이브러리(패키지)를 설치하고 관리하는 `npm (Node Package Manager)` 이나 `yarn`같은 도구가 Node.js와 함께 설치됨

---

### ※ 설치 방법
1. `공식 웹사이트 방문` : [Node.js 공식 웹사이트](https://nodejs.org/ko)에 접속
2. `LTS 버전 다운로드` : `LTS (Long-Term Support, 장기 지원 버전)`를 다운로드하여 설치하는 것을 강력히 권장합니다. LTS 버전은 가장 안정적이며 버그가 적습니다. 이 책에서는 version 22를 사용합니다.
3. `설치 진행`: 다운로드한 파일을 실행하고 기본 설정(Next 버튼)을 유지하며 설치를 완료합니다.

---

- 터미널(Windows: 명령 프롬프트 또는 PowerShell, macOS/Linux: 터미널)을 열고 다음 명령어를 입력

### ※ Node.js와 npm을 더 알아보기
- `npm` : npm은 `Node Package Manager`의 약자로, 전 세계 개발자들이 만든 수많은 JavaScript 라이브러리(패키지)를 손쉽게 설치하고 관리할 수 있게 해주는 도구
- `패키지` : 다른 개발자들이 미리 만들어 놓은 코드 모음
  - 날짜 처리를 쉽게 해주는 `moment` 패키지
  - HTTP 요청을 간편하게 보내는 `axios` 패키지
  - React Native 개발을 돕는 `expo` 패키지
