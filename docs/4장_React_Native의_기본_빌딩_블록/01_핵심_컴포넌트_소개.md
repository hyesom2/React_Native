# 1. 핵심 컴포넌트 소개

View, Text, Image, Button의 기본 사용법 익히기
각 컴포넌트의 주요 Props 이해하기
컴포넌트를 조합하여 UI 만들기
React Native 앱의 화면은 웹의 HTML 태그처럼 미리 정의된 기본 컴포넌트들을 조립하여 만들어집니다. 이 컴포넌트들은 여러분이 작성한 JavaScript 코드를 실제 네이티브(Native) 앱 요소로 변환하여 화면에 보여줍니다.

이 장에서는 모든 React Native 앱에서 필수로 사용되는 네 가지 핵심 컴포넌트를 자세히 설명합니다.

### 1-1&#41; `<View>`: 레이아웃을 위한 컨테이너
- `<View>`는 React Native의 **가장 기본적이고 중요한 컴포넌트**
- 화면의 **영역(Region)**을 잡거나 다른 컴포넌트들을 담는 **컨테이너(Container)** 역할
- 웹 개발에서의 `<div>`와 가장 유사하며, 레이아웃을 구성하는 데 필수적

### ※ 주요 특징
- **역할** : 다른 컴포넌트들을 묶어서 그룹화하고, 스타일을 적용하여 위치와 모양을 결정
- **특징**
  - **스타일링** : 배경색, 테두리, 그림자, 패딩, 마진 등 모든 스타일 속성을 가짐
  - **레이아웃** : Flexbox 속성을 적용하여 자식 컴포넌트들을 원하는 방식으로 배치 가능
  - **비시각적** : 그 자체로는 화면에 아무것도 표시하지 않음(스타일을 적용해야 보임)
  - **중첩 가능** : View 안에 View를 무한히 넣기 가능

---

### ※ 기본 사용 예시
```jsx
import { View, Text, StyleSheet } from 'react-native';

function BasicViewExample() {
  return (
    <View style={styles.container}>
      <Text>안녕하세요!</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    padding: 20,
    backgroundColor: '#f0f0f0',
  }
});
```

### ※ View의 다양한 활용 예제

**① 카드 레이아웃**
```jsx
function Card({ title, content }) {
  return (
    <View style={styles.card}>
      <View style={styles.cardHeader}>
        <Text style={styles.cardTitle}>{title}</Text>
      </View>
      <View style={styles.cardBody}>
        <Text>{content}</Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  card: {
    backgroundColor: 'white',
    borderRadius: 12,
    padding: 16,
    marginVertical: 8,
    // 그림자 (iOS)
    shadowColor: '#000',
    shadowOffset: { width: 0, height: 2 },
    shadowOpacity: 0.1,
    shadowRadius: 4,
    // 그림자 (Android)
    elevation: 3,
  },
  cardHeader: {
    borderBottomWidth: 1,
    borderBottomColor: '#e0e0e0',
    paddingBottom: 8,
    marginBottom: 8,
  },
  cardTitle: {
    fontSize: 18,
    fontWeight: 'bold',
  },
  cardBody: {
    paddingVertical: 4,
  }
});
```

**② Flexbox로 수평 배치**

### ※ View의 주요 스타일 속성
| 속성 | 설명 | 예시 |
| :--: | :--: | :--: |
| `backgroundColor` | 배경색 | `'#ffffff'`, `'red'` |
| `borderRadius` | 모서리 둥글게 | `8`, `12`, `50` |
| `borderWidth` | 테두리 두께 | `1`, `2` |
| `borderColor` | 테두리 색상 | `'#e0e0e0'` |
| `padding` | 내부 여백 | `16`, `20` |
| `margin` | 외부 여백 | `8`, `16` |
| `width` |  height	크기 | `100`, `'100%'` |
| `flex` | 유연한 크기 | `1`, `2` |
| `flexDirection` | 배치 방향 | `'row'`, `'column'` |
| `justifyContent` | 주축 정렬 | `'center'`, `'space-between'` |
| `alignItems` | 교차축 정렬 | `'center'`, `'flex-start'` |

### ※ View 사용 팁

**① 의미 있는 그룹화**
```jsx
// 좋은 예: 관련된 요소들을 View로 그룹화
<View style={styles.productCard}>
  <View style={styles.productImage}>
    <Image source={product.image} />
  </View>
  <View style={styles.productInfo}>
    <Text>{product.name}</Text>
    <Text>{product.price}</Text>
  </View>
</View>

// 나쁜 예: 불필요한 중첩
<View>
  <View>
    <View>
      <Text>Hello</Text>
    </View>
  </View>
</View>
```

**② SafeAreaView 활용 (노치 대응)**
```jsx
import { SafeAreaView } from 'react-native';

function App() {
  return (
    <SafeAreaView style={styles.container}>
      {/* 노치나 상태바 영역을 피해서 콘텐츠 표시 */}
      <View style={styles.content}>
        <Text>안전 영역 안에 있습니다</Text>
      </View>
    </SafeAreaView>
  );
}
```

**③ 절대 위치 지정**
```jsx
function FloatingButton() {
  return (
    <View style={styles.container}>
      <Text>메인 콘텐츠</Text>

      {/* 우측 하단에 고정된 버튼 */}
      <View style={styles.floatingButton}>
        <Text>+</Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
  },
  floatingButton: {
    position: 'absolute',
    right: 20,
    bottom: 20,
    width: 60,
    height: 60,
    borderRadius: 30,
    backgroundColor: '#007AFF',
    alignItems: 'center',
    justifyContent: 'center',
  }
});
```
