# 3. 터치 가능한 컴포넌트들
- 모바일 앱에서 사용자 상호작용은 대부분 **터치**로 이루어짐
- React Native는 다양한 터치 컴포넌트를 제공

---

### 3-1&#41; TouchableOpacity
- 터치 시 투명도가 변하는 컴포넌트
- 가장 많이 사용
- **장점**
1. 간단하고 직관적
2. 자연스러운 피드백
3. 커스터마이징 용이

```jsx
import { TouchableOpacity, Text } from 'react-native';

function OpacityButton() {
  return (
    <TouchableOpacity
      style={styles.button}
      activeOpacity={0.7}  // 눌렀을 때 투명도 (0~1)
      onPress={() => console.log('클릭!')}
    >
      <Text style={styles.buttonText}>터치하세요</Text>
    </TouchableOpacity>
  );
}

const styles = StyleSheet.create({
  button: {
    backgroundColor: '#007AFF',
    padding: 16,
    borderRadius: 8,
    alignItems: 'center',
  },
  buttonText: {
    color: 'white',
    fontSize: 16,
    fontWeight: 'bold',
  }
});
```

### 3-2&#41; TouchableHighlight
- 터치 시 **배경색이 변하는** 컴포넌트
- **장점**
1. 명확한 시각적 피드백
2. 리스트 아이템에 적합

```
⚠️주의
- 자식이 하나만 있어야 함
```

```jsx
import { TouchableHighlight } from 'react-native';

function HighlightButton() {
  return (
    <TouchableHighlight
      style={styles.button}
      underlayColor="#0051a8"  // 눌렀을 때 배경색
      onPress={() => console.log('클릭!')}
    >
      <Text style={styles.buttonText}>터치하세요</Text>
    </TouchableHighlight>
  );
}
```

---

### 3-3&#41; TouchableWithoutFeedback
- 시각적 **피드백 없이** 터치만 감지
- **사용 사례**
1. 키보드 닫기
2. 모달 배경 클릭
3. 특별한 UI 효과가 필요한 경우

```jsx
import { TouchableWithoutFeedback, View, Text } from 'react-native';

function InvisibleTouchArea() {
  return (
    <TouchableWithoutFeedback
      onPress={() => console.log('조용히 클릭됨')}
    >
      <View style={styles.container}>
        <Text>여기를 터치해도 변화가 없습니다</Text>
      </View>
    </TouchableWithoutFeedback>
  );
}
```

### 3-4&#41; Pressable (권장!)
- 가장 **현대적**이고 **유연한** 터치 컴포넌트
- **장점**
1. 최신 React Native 권장 방식
2. 매우 유연한 스타일 제어
3. 다양한 이벤트 지원
4. pressed 상태 활용 가능

```jsx
import { Pressable, Text, StyleSheet } from 'react-native';

function ModernButton() {
  return (
    <Pressable
      style={({ pressed }) => [
        styles.button,
        pressed && styles.buttonPressed  // 눌렸을 때 스타일
      ]}
      onPress={() => console.log('클릭!')}
      onLongPress={() => console.log('길게 누름!')}
      onPressIn={() => console.log('누르기 시작')}
      onPressOut={() => console.log('누름 해제')}
    >
      {({ pressed }) => (
        <Text style={styles.buttonText}>
          {pressed ? '눌림!' : '터치하세요'}
        </Text>
      )}
    </Pressable>
  );
}

const styles = StyleSheet.create({
  button: {
    backgroundColor: '#007AFF',
    padding: 16,
    borderRadius: 8,
    alignItems: 'center',
  },
  buttonPressed: {
    backgroundColor: '#0051a8',
    transform: [{ scale: 0.98 }],
  },
  buttonText: {
    color: 'white',
    fontSize: 16,
    fontWeight: 'bold',
  }
});
```

### ※ 터치 컴포넌트 선택 가이드
| 상황 | 권장 컴포넌트 | 이유 |
| :--: | :--: | :--: |
| 일반 버튼 | 누르는 | 가장 유연하고 현대적 |
| 리스트 아이템	| 터치 가능한 불투명도 | 간단하고 자연스러움 |
| 카드 클릭	| 누르는 | 복잡한 피드백 가능 |
| 아이콘 버튼	| 터치 가능한 불투명도 | 빠르고 간편 |
| 배경 클릭 (모달) | 피드백 없이 터치 가능 | 시각적 피드백 불필요 |
