# 2. 사용자 입력 처리
- 모바일 앱에서 사용자로부터 텍스트를 입력받는 것은 로그인, 검색, 메시지 전송 등 거의 모든 상호작용의 기본
- React Native에서는 `<TextInput>`컴포넌트가 이 역할을 담당

---

### 2-1&#41; `<TextInput>`의 기본 구조와 상태 관리
- `<TextInput>`은 텍스트를 입력받는 입력 필드(Input Field)이며, 웹의 `<input type="text">`와 유사함
- 모바일 환경에서는 사용자가 필드를 터치하면 자동으로 **소프트 키보드**가 올라옴

### ※ 입력 값의 관리
- `<TextInput>`의 입력 값은 컴포넌트 내부에서 직접 관리되지 않음
- React의 `useState` Hook을 사용하여 입력 값을 관리하는 것이 핵심 → **제어되는 컴포넌트(Controlled Component) 패턴**

| Props |	설명 | 용도 |
| :--: | :--: | :--: |
| `value` |	**현재 입력 필드에 표시될 값**<br />반드시 `useState`의 상태 값과 연결해야함 | 필수 |
| `onChangeText` |	사용자가 **텍스트를 입력할 때마다** 호출되는 함수<br />입력된 새 텍스트가 함수의 매개변수로 전달됨 | 필수 |
| `placeholder` |	입력 필드가 비어있을 때 표시되는 안내 텍스트 | 옵션 |

### ※ 기본 코드 구조
```jsx
import React, { useState } from 'react';
import { View, TextInput, Text, StyleSheet } from 'react-native';

function InputForm() {
  // 1. 입력 값을 저장할 State를 선언합니다. 초기값은 빈 문자열
  const [inputText, setInputText] = useState(''); 

  return (
    <View style={styles.container}>
      <Text style={styles.label}>이름 입력:</Text>

      <TextInput
        style={styles.input}

        // 2. value Props: State 값(inputText)과 연결하여 현재 입력 값을 표시
        value={inputText}

        // 3. onChangeText Props: 입력이 발생할 때마다 State를 업데이트
        onChangeText={text => {
          console.log("입력된 텍스트:", text);
          setInputText(text); // 👈 State 설정 함수로 값을 최신화
        }}

        placeholder="여기에 이름을 입력하세요."
      />

      <Text style={styles.result}>입력 결과: {inputText}</Text>
    </View>
  );
}

// ... (스타일 정의) ...
```

### 4-2&#41; 키보드 및 입력 유형 제어
- `<TextInput>`은 모바일 환경에 맞춰 다양한 입력 옵션을 제공하여 사용자 경험(UX)을 개선함

**① `keyboardType` : 키보드 유형 변경**
- 입력할 내용에 따라 적절한 키보드 레이아웃을 표시

| 값 | 설명 | 용도 |
| :--: | :--: | :--: |
| `'default'`	| 기본 키보드	| 텍스트, 일반 입력 |
| `'numeric'` |	숫자 키패드	| 전화번호, 수량 |
| `'email-address'` |	이메일 특화 키보드 | 이메일 주소 입력 |
| `'phone-pad'` |	전화번호 키패드	| 전화번호 입력 |


```jsx
// 숫자만 입력받도록 키보드 변경
<TextInput 
  keyboardType="numeric" 
  placeholder="나이 (숫자만)"
/>
```

**② `secureTextEntry` : 비밀번호 숨김**
- 입력된 문자를 점(`•`)으로 표시하여 비밀번호와 같은 민감한 정보를 가릴 때 사용
```jsx
// 비밀번호 입력 필드
<TextInput 
  secureTextEntry={true} 
  placeholder="비밀번호"
/>
```

**③ `autoCapitalize` : 자동 대문자 설정**
- 사용자가 입력하는 동안 문자를 자동으로 대문자로 변환할지 설정

| 값 | 설명 |
| :--: | :--: |
| 'none' | 자동 대문자 변환 안 함 |
| 'sentences' | 문장 시작 시 자동 변환 (기본값) |
| 'words' | 단어 시작 시 자동 변환 |
| 'characters' | 모든 문자를 자동 변환 |

```jsx
// 모든 단어 시작을 대문자로 자동 변환
<TextInput 
  autoCapitalize="words" 
  placeholder="이름"
/>
```

### 4-3&#41; 고급 이벤트 처리
- `onChangeText` 외에도 `<TextInput>`은 다양한 상호작용 이벤트를 처리할 수 있음

| Props | 설명 |
| :--: | :-- |
| onEndEditing | **입력이 완료되었을 때** (키보드의 '완료' 버튼을 누르거나 필드를 벗어날 때) 호출됨<br />입력 값의 최종 처리에 유용함 |
| onFocus | 입력 필드가 선택(포커스)되었을 때 호출됨 |
| onSubmitEditing | 하드웨어 키보드의 **Enter 키** 또는 소프트 키보드의 **'다음'/'완료' 버튼**을 눌렀을 때 호출됨 (주로 폼 전송에 사용) |

```jsx
<TextInput 
  // 입력 완료 시 콘솔에 최종 입력 값 출력
  onEndEditing={(event) => console.log('입력 완료된 최종 값:', event.nativeEvent.text)}
/>
```
- `<TextInput>`은 이처럼 다양한 Props를 통해 단순한 텍스트 입력 외에도 고도로 제어되고 사용자 친화적인 입력 환경을 구축
