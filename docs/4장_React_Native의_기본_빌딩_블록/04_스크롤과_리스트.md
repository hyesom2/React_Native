# 4. 스크롤과 리스트

### 4-1&#41; ScrollView
- **모든 자식을 한 번에 렌더링**하는 스크롤 가능한 컨테이너
- **장점**
1. 간단한 사용법
2. 적은 데이터에 적합
3. 모든 자식이 항상 렌더링됨
- **단점**
1. 많은 아이템은 성능 저하
2. 메모리 사용량 증가

```jsx
import { ScrollView, Text, View } from 'react-native';

function BasicScrollView() {
  return (
    <ScrollView 
      style={styles.container}
      showsVerticalScrollIndicator={false}  // 스크롤바 숨기기
    >
      <View style={styles.content}>
        <Text style={styles.text}>스크롤 가능한 콘텐츠</Text>
        <Text style={styles.text}>많은 내용...</Text>
        {/* 더 많은 내용 */}
      </View>
    </ScrollView>
  );
}
```

- 수평 스크롤
```jsx
<ScrollView 
  horizontal={true}
  showsHorizontalScrollIndicator={false}
>
  {items.map(item => (
    <View key={item.id} style={styles.item}>
      <Text>{item.title}</Text>
    </View>
  ))}
</ScrollView>
```

### 4-2&#41; FlatList (권장!)
- **화면에 보이는 아이템만 렌더링**하는 성능 최적화된 리스트

```jsx
import { FlatList, Text, View } from 'react-native';

function BasicFlatList() {
  const data = [
    { id: '1', title: '아이템 1' },
    { id: '2', title: '아이템 2' },
    { id: '3', title: '아이템 3' },
    // ... 수천 개도 괜찮음!
  ];

  const renderItem = ({ item, index }) => (
    <View style={styles.item}>
      <Text>{item.title}</Text>
    </View>
  );

  return (
    <FlatList
      data={data}
      renderItem={renderItem}
      keyExtractor={item => item.id}
      // 성능 최적화 옵션
      initialNumToRender={10}
      maxToRenderPerBatch={10}
      windowSize={5}
    />
  );
}
```

- 주요 Props

| Props | 설명 | 예시 |
| :--: | :--: | :--: |
| `data` | 데이터 배열 (필수) | `[{}, {}, ...]` |
| `renderItem` | 아이템 렌더링 함수 (필수) | `({ item }) => <View>...` |
| `keyExtractor` | 고유 키 추출 (필수) | `item => item.id` |
| `ListHeaderComponent` | 리스트 상단 컴포넌트 | `<Header />` |
| `ListFooterComponent` | 리스트 하단 컴포넌트 | `<Footer />` |
| `ListEmptyComponent` | 빈 리스트 시 표시 | `<Empty />` |
| `onEndReached` | 끝에 도달 시 호출 | `() => loadMore()` |
| `refreshing` | 새로고침 상태 | `true`, `false` |
| `onRefresh` | 당겨서 새로고침 | `() => refresh()` |

### 4-3&#41; SectionList
- **섹션으로 그룹화된 리스트**를 표시

```jsx
import { SectionList } from 'react-native';

function ContactList() {
  const sections = [
    {
      title: 'A',
      data: ['Alice', 'Andrew']
    },
    {
      title: 'B',
      data: ['Bob', 'Brian', 'Betty']
    },
    {
      title: 'C',
      data: ['Chris', 'Cindy']
    }
  ];

  const renderItem = ({ item }) => (
    <View style={styles.item}>
      <Text>{item}</Text>
    </View>
  );

  const renderSectionHeader = ({ section }) => (
    <View style={styles.sectionHeader}>
      <Text style={styles.sectionTitle}>{section.title}</Text>
    </View>
  );

  return (
    <SectionList
      sections={sections}
      renderItem={renderItem}
      renderSectionHeader={renderSectionHeader}
      keyExtractor={(item, index) => item + index}
    />
  );
}

const styles = StyleSheet.create({
  sectionHeader: {
    backgroundColor: '#f0f0f0',
    padding: 8,
  },
  sectionTitle: {
    fontWeight: 'bold',
    fontSize: 16,
  },
  item: {
    padding: 12,
    borderBottomWidth: 1,
    borderBottomColor: '#e0e0e0',
  }
});
```

- **ScrollView vs FlatList**

| **특성**	| ScrollView | FlatList |
| :--: | :--: | :--: |
| **데이터 양** | 적음 (~100개)	| 많음 (수천 개) |
| **렌더링**	| 전체 한번에	| 화면 보이는 것만 |
| **성능**	| 느림 (많을 때) | 빠름 |
| **메모리**	| 많이 사용	| 적게 사용 |
| **사용 사례** | 폼, 프로필 화면	| 피드, 상품 목록 |

- **선택 기준**
  - 아이템 < 100개 → ScrollView
  - 아이템 > 100개 → FlatList
  - 무한 스크롤 필요 → FlatList
  - 섹션 필요 → SectionList
